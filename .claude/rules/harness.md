# 하네스: 기능 개발 워크플로

**목표:** 여러 파일에 걸치거나 실제 동작 확인이 필요한 기능 추가/버그 수정을,
구현(folio-builder)과 실행 기반 독립 검증(folio-verifier)을 분리해서 처리한다.

**트리거:** 기능 추가·버그 수정 요청(및 그 재수정/재검증 요청) 시 `folio-feature-team`
스킬을 사용하라. 오탈자 수정처럼 결과를 눈으로 바로 판단 가능한 사소한 변경은
직접 처리한다.
