주제별로 재구성한 기록. 커밋 메시지 자체보다 "무엇을 왜 했는지"

## 1단계 — 초기 구현과 방향 전환 (2026-08-15~16)

- 최초 구현은 Gemini 요약 + Voyage 임베딩 검색을 포함한 "Zotero
  Insight"(`a5dda6f`).
- 곧바로 AI 요약/임베딩 검색 폐기, Zotero OAuth 로그인과 논문 삭제
  API로 방향 전환(`7509ce7`) — AI 요약이 사용자 학습에 도움이 안
  된다는 판단. 해당 판단이 이후 프로젝트 전체의 기본 원칙으로 고정.
- Svelte 기반 웹 UI와 Docker 배포 추가(`750e48a`).
- 모바일 Safari 대상 폴리필 2건(`2b29600`, `bfc5595`), GitHub Actions
  CI(Continuous Integration)/CD(Continuous Deployment) 구성(`2c59170`
  외 2건).

  반복적으로 다듬음(`f797dc0`, `1cdf9d4`, `79f6eb5`, `39a8cf6`,

  접근은 [pdf-zoom.md](pdf-zoom.md)에 정리.
- 참고문헌/각주 링크 내부 점프, 텍스트 선택이 주석 레이어에 막히던
